# 🚀 MarsXZ — Official Website

Добро пожаловать в репозиторий моего официального сайта-портфолио! Здесь собрана информация обо мне, мои основные проекты (написанные на C#, Kotlin и для Android), а также последние видео с YouTube.

🔗 **Живой сайт:** [marsxz-official.github.io](https://marsxz-official.github.io/)

---

## 🛠️ Технологии и стек

Сайт написан на чистом, современном и быстром стеке без лишних тяжелых фреймворков:
* **HTML5 & CSS3** — семантическая верстка, кастомные свойства (CSS Variables), эффект матового стекла (Glassmorphism) и интерактивный фон.
* **JavaScript (ES6+)** — динамическая подгрузка видео, управление темами (светлая/темная) и плавная физика движущихся сфер.
* **GitHub Actions** — автоматическое обновление данных и интеграция.

---

## 📂 Структура проекта

* `index.html` — главная страница сайта.
* `style.css` — стили, анимации, адаптивность и темы оформлений.
* `script.js` — логика интерактивного фона, переключения тем и подгрузки контента.
* `popular_videos.json` — автоматически обновляемый список видео с YouTube-канала.
